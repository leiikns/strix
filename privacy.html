Política de Privacidad

Última actualización: 11 de septiembre de 2026

Esta Política de Privacidad explica cómo Strix puede recopilar, utilizar y almacenar información cuando utilizás nuestra aplicación dentro de Discord.

1. Información que podemos recopilar

Dependiendo de las funcionalidades utilizadas, Strix puede procesar información proporcionada por Discord o por los usuarios.

Esta información puede incluir:

  • ID de usuario de Discord.
  • ID de servidor de Discord.
  • ID de canales.
  • Nombre de usuario o información pública proporcionada por Discord.
  • Configuraciones relacionadas con el uso del bot.
  • Información necesaria para ejecutar las funcionalidades solicitadas.

2. Uso de la información

La información procesada por Strix puede utilizarse para:

  • Proporcionar las funcionalidades del bot.
  • Guardar configuraciones de servidores.
  • Mejorar y mantener el funcionamiento del servicio.
  • Detectar y prevenir abusos.
  • Solucionar errores técnicos.

3. Almacenamiento

La información necesaria para el funcionamiento de determinadas funciones puede almacenarse durante el tiempo necesario para proporcionar dichas funciones.

4. Compartición de información

No vendemos información personal de los usuarios. La información no se comparte con terceros salvo cuando sea necesario para proporcionar el servicio, cumplir obligaciones legales o proteger la seguridad del servicio.

5. Seguridad

Adoptamos medidas razonables para proteger la información procesada por Strix. Sin embargo, ningún sistema conectado a Internet puede garantizar seguridad absoluta.

6. Eliminación de información

Si querés solicitar la eliminación de información asociada al uso de Strix, podés contactar al equipo responsable del bot.

7. Cambios en esta política

Esta Política de Privacidad puede actualizarse periódicamente. Cualquier modificación será publicada en esta página.

8. Contacto

Para consultas relacionadas con privacidad o eliminación de datos, contactá al equipo responsable de Strix mediante el servidor de Discord correspondiente.
